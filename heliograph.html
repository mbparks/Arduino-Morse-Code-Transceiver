About

HELIOGRAPH version

Host console for the Optical Morse Terminal sketch. Reads the sketch's serial output grammar over Web Serial, keeps the station state in view, and checks every received frame's CRC a second time on this side of the link.

License: GPL-3.0

Vendored libraries: none. No build step, no server, no network access. Everything here is hand written and runs from disk.

Feedback: raise an issue on the project repository, or note it in the bring-up log alongside the board.
